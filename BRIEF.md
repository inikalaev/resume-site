# Резюме-сайт — бриф

Цель: современная одностраничная страница-резюме, позиционирование — **Product Engineer**.

## Решения (согласованы)
- **Аудитория:** РФ + зарубежье -> две языковые версии RU/EN с переключателем.
- **Стиль:** продуктовый, с кейсами. Главный блок — карточки проектов: проблема -> что сделал -> результат в цифрах. Опыт, стек, образование, контакты — вторично.
- **Правка данных:** весь контент в одном JS-объекте (`const DATA = {...}`) в начале единственного `index.html`. Названия компаний/вузов в исходном резюме заменены намеренно — должны меняться правкой одной строки в DATA, без сборки.
- **Формат:** один самодостаточный `index.html` (инлайн CSS/JS, без фреймворков и сборки), тёмная/светлая тема, адаптив, печать в PDF через `@media print`.
- **Хостинг:** Yandex Cloud Object Storage (static website hosting) + свой домен + сертификат из Certificate Manager (Let's Encrypt). Открывается из РФ без VPN и из-за рубежа. Cloudflare/Vercel/GitHub Pages — нет: в РФ нестабильны, github с Мака недоступен.

## Дальше
1. Пользователь присылает резюме (с заменёнными названиями).
2. Переписать опыт в формат кейсов под продакт-инженера (импакт, метрики, продуктовые решения), уточнить недостающие цифры.
3. Свёрстать `index.html`, проверить в браузере (десктоп/мобайл/печать).
4. Инструкция деплоя: бакет, `yc storage s3 cp`, домен, HTTPS.
